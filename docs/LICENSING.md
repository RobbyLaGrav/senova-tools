# Licensing, in plain words

Everything here is licensed under the **GNU Affero General Public License, version 3 or later** (AGPL-3.0-or-later). The full text is in [LICENSE](../LICENSE). This page summarises it; the licence itself is what counts.

## You may

- Use any tool for any purpose, including commercial work.
- Read and change the code.
- Share the tools, changed or not.

## If you share or host it, you must

- **Distributing** a tool or anything built on it: provide the complete source code of your version under AGPL-3.0, with the licence and copyright notices.
- **Running a changed version for others over a network** (a web service, an API, a hosted app): offer those users the source code of your changed version. This is what the "Affero" part adds, and why we chose it: our tools are often used as services.
- Keep the licence and copyright notices, and mark what you changed.

Using a tool internally without distributing it or offering it over a network to others doesn't trigger these duties.

## Why AGPL

We want the tools to be free to use and improve, and we want improvements to come back to everyone. AGPL is the standard licence that keeps them open, including when they run as a service.

## Dependencies

Tools only use dependencies under licences compatible with AGPL-3.0: MIT, BSD, ISC and Apache-2.0. Each package lists its dependencies and their licences in its README.

## Contributions

Contributions are accepted under AGPL-3.0-or-later with a `Signed-off-by` line on each commit (the [Developer Certificate of Origin](https://developercertificate.org)). If Senova Systems later offers the tools under a commercial licence as well, it may ask future contributors to sign a contributor licence agreement; nothing already contributed changes licence without its author's agreement.

## Patents

Section 11 of the licence grants users a licence to any patent claims of contributors that the contributed code practises. It does not cover patents held by third parties.
