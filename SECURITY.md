# Security policy

## Reporting a vulnerability

Please report security problems privately through GitHub: **Security → Report a vulnerability** on this repository. That opens a private advisory only the maintainers can see. Don't open a public issue for a security problem.

Include the tool, version or commit, what you found, and the steps to reproduce it. We aim to acknowledge reports within 3 working days and to tell you what happens next within 10.

## Supported versions

Security fixes go into the latest release of each tool. Older releases are not patched.

## Scope

Every package in this repository. Third-party dependencies are reported to their own projects; tell us too if one affects a tool here.
